# Four-week learning path

| Week | Modules | Time | Practical completion criteria |
| --- | --- | --- | --- |
| 1: Foundations | 00–03 | 5–7 hours | Explain driver/executors, run DataFrame and SQL equivalents, read an `explain` plan. |
| 2: Reliable tables | 04–09 | 7–9 hours | Generate raw data, build Bronze/Silver/Gold, quarantine defects, and pass quality checks. |
| 3: Scale and change | 10–12 | 6–8 hours | Use windows/nested data, compare plans, and run a checkpointed local stream. |
| 4: Production | 13–15 | 6–8 hours | Describe UC governance/workflows and deliver the capstone with an idempotent rerun. |

For each module: read concepts, execute cells in order, make one **Try It Yourself** change, complete all six exercises, answer the knowledge check, and record what surprised you. Do not optimize based only on tiny local timings.
